# Paint Online — онлайн полотно для совместного рисования

## 1. Краткое описание
Проект — простое онлайн-поле для совместного рисования в реальном времени. Пользователи создают/вступают в комнаты и совместно рисуют на общем полотне. Клиентское приложение реализует инструменты рисования, чат и базовые модальные окна; сервер обеспечивает WebSocket-соединения, хранение комнат и простую логику синхронизации.

## 2. Основной функционал
- Создание и присоединение к комнате для рисования.
- Совместное рисование в реальном времени (WebSocket).
- Набор инструментов: кисть, ластик, фигуры (круг, прямоугольник, линия, квадрат, эллипс), текст, перемещение (hand), указатель.
- Сохранение/загрузка холста (серверная поддержка сохранения состояния полотна).
- Встроенный чат для участников комнаты.
- Управление размерами кисти и цветом (UI контролы).

## 3. Технологический стек
**Frontend (client):**
- React 18
- MobX (`mobx`, `mobx-react-lite`) — хранение состояния клиентского приложения
- Axios — HTTP-запросы
- React Router — маршрутизация
- react-draggable — перетаскивание/манипуляции

**Backend (server):**
- Node.js + Express
- WebSocket через `express-ws`
- Sequelize ORM + `mysql2`
- dotenv / config-файлы для конфигурации

**Инструменты и вспомогательные пакеты:**
- `nodemon` для разработки сервера
- `uuid` для генерации идентификаторов

## 4. Архитектура и структура репозитория
```
project-root/
  client/                 # фронтенд приложение (React)
    public/
    src/
      Components/          # Canvas, Chat, Toolbars, Modals
      Handlers/            # логика событий (рисование, отправка, загрузка)
      Pages/               # CanvasPage, MainPage
      Store/               # MobX стейты: CanvasState, ToolState
      Tools/               # реализации инструментов (Brush, Eraser, Shape...)
      Resources/           # стили и изображения
  server/                 # backend (Express + WebSocket + Sequelize)
    config/                # пример конфигурации БД (`configExample.json`)
    migrations/            # миграции БД (Sequelize-style)
    models/                # модели
    Database.js            # инициализация Sequelize
    server.js              # точка входа (Express + express-ws)
```

### Ключевые принципы архитектуры
- Простая разделённая архитектура: клиент — UI/логика синхронизации, сервер — транспорт и минимальное персистирование.
- На клиенте: компоненты + store (MobX) + handlers для событий рисования.
- На сервере: Express + WebSocket (express-ws) для трансляции действий между участниками.

## 5. База данных
- В проекте используется Sequelize с драйвером `mysql2` (конфигурация в `server/config/config.json`).
- Основные сущности: `Room` (см. `server/models/Room.js`) и таблицы/миграции в `server/migrations/`.
- Файл `server/Database.js` читает `server/config/config.json` (раздел `development`) для инициализации подключения.

## 6. Слой данных на клиенте
- Клиент хранит состояние полотна в `src/Store/CanvasState.js` и инструменты в `src/Store/ToolState.js`.
- Для HTTP-запросов (сохранение холста, запросы комнат) используется `axios`.
- Синхронизация в реальном времени идёт через WebSocket-соединение, реализованное на сервере.

## 7. UI / Компонентный подход
- Компоненты разделены на атомарные (кнопки, инпуты), контейнеры (Canvas, Chat) и модальные окна.
- Стили лежат в `client/src/Resources/Styles/` и оформлены CSS-файлами для каждой части интерфейса.

## 8. Качество кода
- Код организован по зонам ответственности (модели, handlers, инструменты).
- Минимальные зависимости и простая структура помогают поддерживать читаемость.
